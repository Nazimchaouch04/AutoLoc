Où en est le projet

Chaque atelier ajoute une couche à l'application. Les deux premiers sont terminés.

  1. Atelier 0terminéEnvironnement de travail et dépôt Git « AutoLoc ».
  2. Atelier 1terminéProjet Spring Boot + Maven, connexion MySQL, 9 entités JPA, profil dev et données de démonstration.
  3. Atelier 2prochainAssociations entre entités, cascade et fetch.
  4. Atelier 4Couche service : la logique métier.
  5. Atelier 5Contrôleurs REST.
  6. Atelier 6DTO et validation des données.

Les 9 entités du domaine

Chaque entité devient une table générée automatiquement par Hibernate. Les liens entre elles arrivent à l'Atelier 2.

Vehicule

immatriculation, marque, modele, categorie, tarifJournalier, statut

Agence

nom, ville, adresse, telephone

Client

nom, prenom, email, telephone, numPermis, dateInscription

Employe

nom, prenom, role

Equipement

libelle

Reservation

dateDebut, dateFin, statut

Contrat

dateSignature, montantTotal, valide

Paiement

montant, datePaiement, modePaiement

Maintenance

dateDebut, dateFin, description

5 énumérations : StatutVehicule, CategorieVehicule, RoleEmploye, StatutReservation, ModePaiement.

Technologies

Ce qui fait tourner l'application aujourd'hui.

Java 17
Langage de l'application.
Spring Boot 4.1
Framework : configuration et démarrage automatiques.
Spring Data JPA et Hibernate
Enregistrement des objets Java en base, génération des tables.
MySQL / MariaDB
Base de données autoloc_db.
Lombok
Getters, setters et constructeurs générés, sans @Data sur les entités.
Maven
Dépendances et compilation.
Profil dev
Configuration de développement séparée et 3 véhicules de démonstration.
